# Bounded QLever public string probe

This implements the independently reviewed [shared contract](CONTRACT.md) as a
separate small extension. Its expected arrays remain in [oracle.json](oracle.json).
All five paths are UNEXECUTED until an actual attempt; the first proposed job
collects only QLever Datalog and native SPARQL over one physical foundation.
The original20families/71tasks/142expectations remain unchanged.

The public dependencies are current compiled Core and QLever exports. The
reviewed `loop-v2/inputs.mjs` collector captures recursive installed runtime,
type and compiler packages, including transitive dependencies. Before and after
guards compare those current installed bytes and the public/source inputs.
This is a checked installed layout, not an immutable copied runtime, a package
consumer test or a complete off-platform/conditional environment claim.

## Finite phases and observations

The worker uses exactly the31 named SDK operations in `SDK_CALLS`. Each name may
run once; a120s SDK dispatch window and a5s signal deadline per call apply.
Native reads additionally have5s native/provider timeouts,32row and2MiB response
caps. F1 Datalog reads use persisted/MINUS/paired/bounded, Eoff, with the same
stricter5s/32row/2MiB semantic-probe caps. These are not the old packet's timing
profile. Schema writes and journal/history reads use the actual public runtime;
their internal precondition/admission/native requests are charged, not assigned
a fictional one-request bound. The SDK may request normal cancellation during
abort/close; neither return nor timeout proves physical query cancellation.

1. Read baseline settings100. Two fresh public empty reads, two schema seed
   commands and their command receipts run at100. There are four ASCII and
   seven Unicode entity labels, all valid on `[10.25,10.75)`.
2. At100, verify exact ASCII payload membership. Retain Unicode membership as
   its own normative exact-payload case. Execute native ASCII ASC/DESC/ranges
   and first `LIMIT2 OFFSET0` at the captured ASCII P1.
3. Set/read planner1. Under F1, run Datalog ASCII membership, order and explicitly
   ordered wrapper ranges; capture the actual first page and opaque cursor.
4. Make the one declared `c→0` correction command, prove its ACK by command ID
   and retain full history. Continue/reopen using the identical original cursor,
   never a re-encoded cut. Each Datalog call creates a new public runtime; the
   second continuation is therefore also a reopened adapter read.
   The initial runtime clock is1000.25; the correction and later runtime reads
   use2000.25. The old cursor retains its original P1/R rather than resolving a
   later cut. Public history proves original/new IDs, exact c/0 values, validity,
   assertion and retraction transaction IDs, correction instant and command P2;
   it does not invent private position columns on public Triple records.
5. Read latest P2 and retain Unicode Datalog membership and raw observed order.
   The broader Unicode order remains POLICY_UNRESOLVED, with independent
   alternative arrays, and receives no selected ordering oracle.
6. Restore/read100. Continue native P1 with `OFFSET2`, close/reopen the native
   public client and repeat the same P1 continuation. Read latest P2. Run the
   two normative native Unicode cases only if exact Unicode payload membership
   passed; otherwise retain UNEXECUTED_DEPENDENCY_FAILED, not invented answers.
7. Finally set/read100 even if the setting ACK was lost. Normal completion has
   seven fixed settings controls: before, select1, selected1, restore100,
   native-after100, finally-restore100, finally-read100. An early setup failure
   instead reads unchanged100 without selecting1. At most nine distinct control
   IDs are permitted by the worker. No arbitrary admin command is exposed.

The three intended commands create12 assertion versions and one retirement;
their actual receipts, command records, correction/history, raw native terms,
typed responses, debug query text, cut/cursor and order are retained. Scopes are
fresh UUID-bearing test identities. Nothing is deleted or replayed automatically.
These are11 logical subject IDs, not a configured-entity capacity measurement.
The report counts actual asserted/retracted receipt rows and retains their
schema/type annotations; configured presence/type-version state is not separately
qualified. No extra fixture is introduced to change that distinction.
The actual schema handle accepts a raw string and encodes its TripleValue; the
worker checks that output against `string(value)` before calling transact. It
does not pass a doubly encoded TripleValue into the text handle.

## Failure and oracle policy

An incorrect ordered answer is a semantic FAIL. The frozen diagnostic continues
only to the remaining declared cases, preserves every original returned order,
and records the first-page dependency on later continuations. Complete P1
membership across two pages is a distinct property; it cannot clear a wrong
first page or wrong range/order. The native path uses authored fixed-P1 native
pagination, not an invented opaque SDK cursor.

Unknown ACK, HTTP/SDK/ownership failure, source drift, privacy failure or budget
breach stops remaining cases. No operation is retried and no response is
normalized, casefolded, reordered or replaced to meet its expected array.
Finally restoration and client close are attempted and their actual outcomes
retained; a missing restoration is not inferred successful. No recovery occurs.

The controller compares two separate answer files against independently frozen
expected rows and one actual settings/cleanup file. Unicode membership is
represented by fixed identity plus returned/unique counts and a separate exact
membership flag, while its original raw array is retained unchanged. Object
keys alone are canonicalized for byte comparison; arrays preserve order.
Missing first cursor is retained as a semantic FAIL and skips only the two
cursor-dependent calls; independent latest/native/Unicode cases continue.
Unexpected terminal cursors are semantic failures, retained in the separate
public-invariant oracle. A wrong returned cut or correction lineage is retained
before the dependent packet stops. No response is discarded by its validator.
Every Datalog page additionally checks the captured original recordedAt1000.25,
including continuation after the current runtime clock advances to2000.25.
Native and queryAll calls do not invent an explicit recordedAt requirement.

The primary queue path is `qlever-datalog` with two explicit per-surface result
files/profiles. This is one settings-exclusive combined semantic packet, not
two independent cohorts or a142packet. No other QLever job may be active. Other
engines may co-run only when canonical vector admission allows, with actual
cohorts retained. Client896MiB/1CPU/64MiB/180s and resident Q2GiB are unchanged.
Artifact JSON is limited to2MiB per file and32MiB total; stdout/stderr8MiB leave
headroom in64MiB. Logs retain bounded class/message hashes instead of raw errors.
No stop/start/copy/mount/fault action or public/backend default change is part
of the probe. Unique labels do not qualify equal-label ties.
