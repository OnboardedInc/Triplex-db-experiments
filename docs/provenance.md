# Source provenance

## This repository

This repository is Onboarded's database research, built on a copy of
[Triplex](https://github.com/bjacobso/triplex) by Ben Jacobson (MIT License). The copy came in whole
with the first commit and Onboarded then changed it in place. Triplex is not a dependency here and
the copy is not synchronized with the upstream repository. The
[notice file](https://github.com/OnboardedInc/Triplex-db-experiments/blob/main/NOTICE.md) lists which
parts are Triplex's and which are Onboarded's.

## Upstream Triplex

The rest of this page is the upstream Triplex provenance text.

Triplex began as the database subsystem of an earlier private application repository.

The initial import was filtered from source commit
`473753746f7c8f40c059edf81cca47a8e04202ef` and retained the history affecting:

- `packages/database`
- `test/stress`

The filtered history is merged into this repository, preserving commit authorship and messages.
After import, the packages were renamed and flattened into the standalone package family. The
source application is not a dependency and is not automatically synchronized with this repository.
