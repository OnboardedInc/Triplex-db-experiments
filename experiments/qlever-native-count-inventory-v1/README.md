Proposed source/manifest only; no new native call is authorized by these files.
The prior `qlever-native-readonly-preflight-v2/0001` remains failed at the200000
row continuity guard. Its exact COUNT and named/default channel were not retained.
This new diagnostic cannot retroactively establish them.

This reader admits only the reviewed structured `count` descriptor and fixed
version/settings/activity observations. It explicitly rejects namespace/payload
page descriptors, raw query strings, mutations, setting changes, redirects,
cancellation, copy/mount, owner changes and recovery. Docker remains GET-only.

payload stream occur. The query text/population is retained and counts are exact
integer decimal strings. RDF populations are not domain entities or active facts.

its acceptance condition. Each COUNT response is acquired through a256KiB
bounded tee: exact credential-free JSON wire bytes and their SHA are written
before numeric decoding. Stage/channel and client wall timings are recorded
incrementally. A malformed/oversized/credential-echo reply has safe hash/length
evidence instead of unsafe raw text. Any later parse/API/budget failure preserves
the earlier count/phase files; no generic failure can erase or relabel them.

unchanged2GiB Q and3GiB X foundations charged once. Counts have a30s combined

fingerprint are declared; no complete stdlib/dynamic-runtime/npm closure is claimed.

retry, settings restoration, native cancellation, server action or owner
