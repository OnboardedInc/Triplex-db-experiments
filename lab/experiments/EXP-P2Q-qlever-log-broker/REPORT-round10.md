## Change

The global `isConstructedRead` marker is removed. Each actual service module owns a private constructor instance with its own private WeakSet: Triples, broker storage, Datalog executor and native queries. Only that instance's wrapper adds functions to the set. Exported predicates can inspect membership but cannot mint it; generic helper constructors and another constructor instance cannot supply native provenance. The approved dispatch continuation remains the actual gated native/Datalog answer path; snapshot wrappers still apply the shared basis policy and mask. The generic helpers carry no service marker.

All builders enumerate `Reflect.ownKeys` and own data descriptors, including symbols and hidden own entries. Inherited tables and accessor entries are rejected before invocation. Numeric keys and unbounded index signatures are rejected by the public type signatures; numeric-shaped runtime keys also fail construction. Runtime output contains every accepted own operation key as an enumerable, immutable callable, so assembling the service preserves symbols and hidden input entries. The captured snapshot operation fields and policy function cannot be redirected by later mutation of the input descriptors.

The descriptor guard now receives the actual service-specific predicate and walks every own/inherited string and symbol property without skipping shadowed keys. Writes, position introspection and plan-only methods retain their explicit non-read exemptions. All 24 ordinary read routes remain covered by the existing exact-cut tests.
