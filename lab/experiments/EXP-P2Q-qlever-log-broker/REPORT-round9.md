Reviewer direct, inherited and merged source mutations are applied to the real contracts/implementation in a compiler host; all must produce the missing-table type error. Runtime own/inherited additions use the exact reviewer bypass function and must fail the identity guard. Original reviewer probe files are retained byte-for-byte under `lab/verify/P2Q/round9-probes/`; adapted probes avoid changing the reviewed checkout.
