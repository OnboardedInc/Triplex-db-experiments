Builder CX-P2Q-R3. Work remains on exp/P2Q-qlever-log-broker; broker stays default-off. Implementation and builder gate coverage are complete. Independent acceptance remains open.

The public read functions now come from construction tables. Repository and storage entries declare execution, basis selection and raw-history behavior together; their constructor unconditionally encloses execution with the broker snapshot policy. Query facade entries translate arguments to the sole existing gated answering continuation. Constructed reads are tracked by function identity. Assembled services are frozen with null prototypes. Existing writes, position introspection and plan-only operations are explicitly exempt from snapshot execution, not certified as reads.

Resolved TypeScript `Omit` coverage checks bind the public interfaces to the constructed tables; `keyof` includes inherited and merged declarations. A separate compile-only Triples interface/table test runs under the source-alias typecheck. Runtime regression walks every own property and the entire prototype chain, rejecting unconstructed callables/accessors outside explicit non-read exemptions. Reviewer direct, inherited and merged source mutations are applied to the real contracts/implementation in a compiler host; all must produce the missing-table type error. Runtime own/inherited additions use the exact reviewer bypass function and must fail the identity guard. Original reviewer probe files are retained byte-for-byte under `lab/verify/P2Q/round9-probes/`; adapted probes avoid changing the reviewed checkout.
