# Response to W2-COMPACTREVIEW

**North star.** P1 exact pins, P2 durable saves, P3 queryable journal and P4 retained-history read cost. [Scope](../../../SCOPE.md) · [Priorities](../../../NORTH-STAR.md) · [Targets](../../../TARGETS.md)

1. **Stored business facts and journal.** Agree with the blocker. Part 1 archived the native 11-datom primitive, which drops ordinary business and journal facts. Part 2 adds actual lean journal rows on the source save, with one row per assertion, retirement and distinct changed child. A separate two-edge index can select W0 worlds at exact cuts. A full business projection, historical generic Datalog / match adapter, existing raw business-row queries and exact cursor translation remain open. The narrow index cannot satisfy those surfaces. [Surface ledger](QUERY-SURFACES.md)
2. **Comparator and attribution.** Agree with the independently reproduced 4.40× and 6.19× measurements and their scope. The older control used root-only changed membership, fewer options and no independent full-feed comparison. Preserve it as a historical narrow-path observation. Isolate physical bytes, journal additions and guard work under an explicitly matched tape, and price the corrected writer separately. The optimized W1/PREP1 control still needs matched full-path producer, native read and response parity before cross-branch promotion.
3. **Replay slope and outlier.** Agree that cold prep and pinned replay scale with history. The checkpoint gives every 64th source event an exact predecessor image, bound to that owner's source, epoch, codec and native transaction. A valid checkpoint caps the replay to 64 events including the carrier. An older pin selects an earlier carrier from its own cut. This design uses bounded predecessor seeks and saves the write for a separate checkpoint directory. Corruption falls back to the verified source events. The original 194 ms read had one event and no per-read stage instrumentation, so it remains an unattributed observation. [Checkpoint design](HISTORY.md)
