# DX-B9 verdict/receipt audit (pending selected-source gate union)

No script here grants lab acceptance or edits its contract. Performance rows are diagnostic.

- `summarize.py`: reads all four arm reports; checks arm identity, positive actual samples,
  logical head >=50k, four distinct owned stack identities and source-manifest hash linkage.
  Reports both repeats; only non-overlapping ranges count as a difference. A failed outer
  attempt remains failed, even if its phase JSON files exist. Fresh prefixes/directories
  bind reports to this hold. It does not compare historical numbers with a new arm.
- `clone2-window.sh`: each clone has an equal file-name set and SHA256 content versus the
  sealed read-only input before startup. `du` is used only for the cap. Each fresh driver
  verifies the existing scope and exact logical head. Native `t` can advance at startup;
  actual before/after values are retained. All four workers hash every returned JSON byte
  across2,000 warm roots, with positive byte counts; B1/A2/B2 must equal fresh A1's counts,
  byte totals and hashes. The reference file is created with A1 in this hold, never borrowed.
  These are JSON-answer equivalence checks for the representative graph, not an oracle for
  arbitrary native metadata queries or full TARGETS traffic acceptance.
- `clone-window.sh` seed sealing: requires the actual driver to finish, clean stopped PG
  exit0 and an observed size below its cap. `sealedSeed:true` means a closed physical input,
  not a W0 fingerprint/PASS. Input scope, receipt cut, source bytes, stack/container IDs and
  image/durability observations remain in the attempt. Only this explicitly retained volume
  is allowed outside the seed hold; each measured clone is removed immediately.
- `load*.mjs` / `mixed*.mjs`: preserve B8 checks on exact ACK position/t, response diagnostics,
  and every moving reader's driver-recorded ACK cut, monotonic feed position and tx identity.
  Samples are actual new responses in fresh/cloned scopes, with exact source/build captures.
  Added instrumentation retains gateway timelines; it does not manufacture latency or success.
- `native-tests.sh`: uses actual Clojure assertions, zero-error exits and the captured mounted
  source. The new key test checks generation, full safe-integer coordinates and CHM equality;
  B8 lifecycle/hot/recent tests remain unchanged. No historical count is treated as execution.
- `short-diff-gates.sh` / `parallel-gates.sh`: preserve every original scenario and assertion;
  independent child exits are retained. Verified-cache checks require enabled verification,
  positive hits, every hit verified, no mismatches, and all component budgets. Proxy counts
  actual socket opens and caps physical Mac-to-VM sockets at64.
- `verify-gates.py`: requires successful fresh short/long holds, complete expected file/test
  counts for both layouts, three contiguous RNG shards and the exact95028/5664 denominators,
  actual native assertion summaries, current mounted source preimages, matching source IDs,
  fresh verified-cache counters, observed cleanup and lease bounds. It emits a developer gate
  union only; any missing/failing input prevents a union. Rejected/aborted attempts stay rejected.
- Every cleanup receipt has `semanticVerdict:null`; empty inventories, observed exits and
  owned name checks concern lifecycle only. They never promote a correctness result.

Step-B draft files and `apply-step-b.py` are unexecuted proposals. Their tests are not counted.
The W0 test fixture repair preserves its original data/order/basis/round-trip assertions;
actual source and built clients are both observed. The new sweep ordering guard rejects
unreachable nonempty bodies rather than silently dropping rows. No assertion was relaxed.

- `original-arm-binding.json`: all8 original fresh arm manifests were checked against exact Git
  file bytes (A19f5422d, Bda77a50a), including the codec preimage; manifest path and full revision
  are retained. This validates source identity, not semantic results.
- `write-report.py`: copies complete four-arm summary rows, labels missing summaries/gate union
  PENDING, and preserves busy-host and missing-metric limits. Final regression interpretation uses
  the retained non-overlapping ranges, never a historical-versus-current comparison.
- `finish-cleanup.sh`: requires the final clone hold's successful bounded exit, then under its
  own lock proves the exact retained source volume has no attachments, removes only that volume
  and observes absence. Its receipt has semanticVerdict:null and grants no correctness PASS.

- Summary binding additionally rejects repeat-source drift and reused container identities across
  all16 observed engine containers. Selected summaries check every manifest path digest against
  stage-default1's actual A/B preimages.
- `compress-evidence.py`: a new compressed path must not exist; original length/hash is recorded,
  actual decompression must match both, and a path mapping is retained. This is lossless storage,
  not a semantic verdict. `manifest.py` requires completed selected gates and cleanup, hashes
  every durable file, rejects files changing size/mtime while read, and splits integrity shards
  below1MB. It never turns an integrity check into semantic PASS.
