The fixture enrolls both eras before their first writes. It seals protected values and journal bodies in the same native transaction. The move carries every account together at one cut, preserves assertion IDs, and re-seals each live value with the successor's scope as authenticated context. Old keys and new keys for a carried assertion have distinct authority paths.

The coordinator writes a single pending entry across both eras. It prepares, appends and content-checks each native erasure using the same erase instant and logical identity. The first run deliberately stops after the archive's publication. A routed current read, archived pin and feed request must all fail closed while the shared frontier is pending. A retry uses the exact prepared bytes and commits the second era, advances the shared ledger, and revokes both sets of keys. An already published retry revokes any remaining keys idempotently. Held database values are decoded using the current verified frontier.

The native archive records its own erasure metadata after the business cut. The logical feed emits the successor erasure once and keeps the archive's originally routed business positions. The drill compares full current and pinned facts, old and successor held views, receipt resend, feed row identities, a sibling control, the typed erasure metadata, raw history and log strings, ciphertext existence and key absence.

This is a small router fixture. It covers its designated protected string, one move and one interrupted erasure. External snapshots of authorities, client-held plaintext, rotation, backup replay across both eras and production routing remain outside this proof.
