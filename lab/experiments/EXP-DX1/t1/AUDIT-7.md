# Part 7 observation audit

The acceptance contract is unchanged. Derived reports copy observed bars; they do not promote an implementation.

- `study.mjs` retains the existing DONE, exact 10,000-subject workload, source/build, run/slot/session and raw collector checks before reproducing benchmark bars. Each pair's independent oracle binds newly observed command/read bytes to frozen executable oracle inputs. Off controls are session context, not a tracing-cost experiment.
- `session.sh` stress mode adds a fresh zero-reader arm under the same source-frozen measurement lease. It preserves the 45-second reader phases and frozen generator; its 450-second diagnostic is explicitly not a full verdict pair.
- `ablation.mjs` validates DONE, the 3,707-command frozen diagnostic prefix, exact writer timestamp/latency content, raw source/build/runtime identity, native settings/affinity and fresh host samples. Stress ratios additionally require the same-session zero arm to precede this arm, exact source/slot/session, matching harness bytes and a SHA256 of the actual baseline writer file equal to the driver's bound denominator. Existing driver baseline loading verifies completed committed writer bytes and reproduces matched-window ratios.
- `validateBasisBroadcast` compares every observed broadcast's measured interval, source/run/slot/thread, mode, item counts and histogram against the report. Delta has the same exact receipt suffix and sampling rules as snapshot. A gain must exceed both fresh baseline drift and both individual control values.
- Compression selects only the two explicitly incomplete part-4 attempt directories, checks source ages/quiescent owned-engine inventory, and writes an original SHA256 per file. Zstd integrity plus the decompressed SHA256 must match before a compression is counted; compressed hashes and restore commands are retained in the private journal. An archive check is not a semantic PASS. The original attempt manifests continue to describe the recoverable original bytes.

The first broadcast trial retains one snapshot-control ReadError (socket queue/write, no response) and therefore produces no A/B/A latency-gain verdict. The candidate and closing control completed with fresh oracle PASS; no failed read is removed. A retry is a new attempt. Stress comparisons now collect a separate candidate-mode zero-reader denominator as well, and verify wire/expected-model mode equality before reporting either writer-tail ratio.

`ModelJournal` captures intent/receipt/commit frames synchronously before releasing their object graphs. Explicit wire Options preserve Effect prototype tags; scalar, byte and temporal values use V8's lossless serializer. At drain it seals and fsyncs, checks exclusive file creation, exact length, sequence, source/run/slot/subject identity and SHA256, and returns a model only after every frame replays successfully through the unchanged full-row checker. A corrupt, missing, extra, duplicate or foreign frame fails before any model verdict. The independent oracle and all-read comparisons still run after restore; measured offer-to-completion timestamps and engine durability are unchanged. GC kind/flags and per-isolate heap spaces are telemetry only, with no new acceptance rule.

`writerStats` refuses unfinished/off attempts, foreign/stale writer-isolate records, duplicate/missing primary identities and measured-boundary mismatches; it requires one raw root per actual primary writer row and timed heap samples. Counts and percentiles use the complete writer population. GC, heap and scheduler-lateness intervals remain observed metrics; union episodes are separated from overlapping per-command intervals. Outputs are exclusive new files and carry original run source plus current renderer SHA256. The corrected stress caption does not alter observations; original outputs stay retained, and the re-render checks the same raw source/build/slot/host/runtime/baseline content. No new semantic PASS is emitted.

Journal archival runs only after complete model replay: exclusive gzip creation, decompressed byte count and original SHA256, compressed SHA256, fsync of archive/metadata/directory precede removal of the redundant original. Corrupt or incomplete archives cannot produce a receipt or a model verdict. Ablation checks both compressed and decompressed bytes against the fresh source/run/slot-bound model receipt; ordinary engine durability and acknowledgement timing are untouched. A second archive refuses; earlier attempt files are never overwritten. Tests retain temporal/retraction/Option semantics, signed zero, structured values, tamper/truncation and archive round trips.
The first model session was refused below 15 GiB before lease/container creation. New compression is restricted to incomplete comparison/verdict attempts and smoke raw files, with report/source manifests and viewers retained. Original bytes remain losslessly recoverable with per-file hashes and restore commands.
