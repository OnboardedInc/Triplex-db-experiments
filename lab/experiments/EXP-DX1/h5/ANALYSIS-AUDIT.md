# Derived table audit

`analyze.mjs` is not a verdict producer. It copies receipt statuses and gate statuses, reads only retained completed-page metrics, distinguishes missing observations, and reports overlapping demand separately from wall time. A failed receipt remains failed; metrics from a failure remain an ACK-metric prefix, not global exact coverage. Its CPU estimates label worker thread costs separately from overlapping main-thread/live intervals and label the no-live preview's main/write-gateway calibration. A CPU projection is conditional arithmetic at the stated 440,000 input rows/s, never a fresh 100k result or acceptance PASS.

`manifest.mjs` requires fresh empty owned-container/network inventory, no H5 measurement lease, and a terminal outer exit for every attempt before hashing. It streams actual bytes, checks file size/mtime stability and refuses to overwrite a final manifest. Split committed checksum parts stay below 1 MB; hashes bind evidence bytes, never a semantic verdict. The final native checksum verification is recorded separately. `source-types-final.json` records only the actually observed compiler exit and source/configuration hashes; it does not grant engine or P5 correctness. Reference command counts are existing generator metadata, not measured seed outcomes.

`CHECKSUM-VERIFICATION.json` records the observed zero exit of the actual native shasum checks over all9768 raw files and the split-manifest hashes, with exact manifest digests and observation time. It validates preservation against these manifests, not correctness, original Git provenance or P5 acceptance. No raw evidence was written after final manifest generation; checksum-exit metadata lives only in the committed h5 directory to avoid a self-reference.
