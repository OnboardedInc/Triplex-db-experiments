# Sweep prerequisite audit

`sweep-after-gate.sh` waits for the unique `tx2-dxh5-equivalence1` attempt created in this run; the controller refuses existing attempt arguments rather than overwriting an old prefix. It never treats a missing file or terminated gate without a verdict as success. Before starting a configuration it requires MATCH, eight comparisons, one Agent-level request each, and equality of every recorded gate-source hash with current bytes. The producer itself compares complete portable/selected row bytes at both fresh cuts, then rechecks those sources. This is an admission prerequisite, not a P5 acceptance verdict. All configurations subsequently clone the sealed volume, rerun independent G0/counts, capture their own activation basis and execute every existing activation gate. Heavy tokens and the measurement lock separately serialize actual resource use; queued launchers create no engine containers.
