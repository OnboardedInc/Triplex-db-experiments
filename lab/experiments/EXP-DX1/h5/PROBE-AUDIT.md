# Concurrent seed probe audit

The probe is diagnostic at N=1000 by default. Each configuration has a fresh scope, full command/ACK log, measured peak in-flight count and actual reference-position mismatches. Its only completion check requires every expected command, unique dense actual positions and full subject-plan execution. This does not replace G0 or grant reference-seed correctness. Each subject's commands remain ordered, while different subjects may interleave. A failed configuration records its nested first cause, drains already-started commands before closing the log/client, remains a failed prefix, and does not prevent an independent fresh-scope configuration from running. Original failures are retained, not rerun in place. The wrapper binds source/build hashes, exact stack/CPU/image identities and cleanup; a faster reordered probe is never sealed or promoted.
