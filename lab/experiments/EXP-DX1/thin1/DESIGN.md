# DX-THIN1

At 100,000 never-read eight-fact imports the eager reader added 667 MB RSS and the compact test model added 310 MB.
The reader held 124 MB of packed rows, a 24 MB shared lookup table and 1,563 bootstrap pages. History was empty.
P1/P4 favor removing the bootstrap entirely. An idle eviction window would still pay its peak cost while importing.

Use a named touched-subject option. Keep the eager replica as the control.
Start the touched replica at a verified scope cut with zero roots. Consume the ordered journal without inline replacements.
Every transaction advances the watermark. Read changed entities only if they already belong to a resident world.
On an actual read, load the reachable rows at its exact position and valid time. Install only into the same live generation and cut.
Publish admission separately from a transaction. Each new entity's readable history begins at admission.
Time-only, missing-reference and older cuts without a local proof take the existing exact gateway path.
No synthetic requests. Keep seed state out of reader processes. A separate streaming driver records real receipt identities on disk.

P5 uses a durable scoped import roster. Admit a seed certificate only for validated W0 answer links and owned answer fields/values.
R1–R3 never read those attributes. Evaluating their empty projection gives the same work items, including the empty-subject defaults.
Any later journal touching the placement or its owned entities makes it a full evaluation from that position onward.
A certified placement has no edges to shared entities. An unrecognized release, seed or changed world takes the full pinned evaluator.
Check contiguous journal positions. Enumerate actual roster IDs once in key order and compare their count and hash with the independent import manifest.
Evaluate and return a publication record for every ID, including empty records that can retire earlier work. Never admit a sweep into the live reader.

On the guest compare full bytes, cut boundaries, first-touch races, RYOW, feed replay and release coverage.
Report observed component memory separately from live gateway, Postgres and transactor measurements.
On the bench stream batches and pinned checks for 1M then 4M. Keep evidence bound to each fresh stack and seed.
