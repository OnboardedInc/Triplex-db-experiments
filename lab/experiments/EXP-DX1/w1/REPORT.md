**Implementation.** `TX2_GROUP_COMMIT=1` enables one queue per database connection at the write gateway. An idle arrival goes alone immediately. A busy queue takes up to eight already waiting commands, round-robin across accounts, FIFO within each account and behind common subject, fact, claim or ordered-sender predecessors. Capacity is 256 queued and 128/account. Explicit namespaced owners or validated `groupAccount` membership assign the share. Unclassified writes share one class.
The gateway runs the existing installed command on successive immutable Datomic views. Native transaction functions invoked side by side would each see the same starting database. One guard checks the exact native basis before persisting the translated changes, the distinct logical receipts and the physical append. A conflicting member advances neither clock nor position. On a definitive native race there is at most one failed group and one ordered solo attempt per member. At most seven other members precede an eligible save within a selected group. These are work bounds. Storage stalls still affect wall time.
