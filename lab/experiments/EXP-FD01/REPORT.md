North star: P3, ordered resumable change feed; zero gaps, per-subject order violations and duplicate visible effects, and byte-exact resume. Goals derive from `lab/SCOPE.md`, `lab/NORTH-STAR.md` and `lab/TARGETS.md` 1.1 P3. Design: R41 sections 1–5, Q98a–j, Q31c, Q84a, Q90 and Q95.

## Result and scope

Built the lane-neutral offline foundation on `exp/FD01-feed-contract`, from main `daeb442226fd50f70323dde0ada5452d93ecfd45`. This is builder evidence, **not NS.P3 closure, a lane promotion or independent verification**. No engines, Docker, live endpoints or engine slots were used. No acceptance files were edited. Nothing was pushed or merged.

Delivered:

- Public core `/feed` contract: source-bound cursors; commit, aborted, epoch and seal resolutions; exact decimal-string coordinates/stamps; per-operation positions, transaction/command IDs and identity-only assert/retract/erase tuples; erasure sequence; nullable pending-RT01 stamps. Canonical bytes reject missing identities, unknown fields and values/envelopes/key IDs.
- Host `/feed` SQLite ConsumerStore: WAL, FULL, fullfsync, checkpoint_fullfsync, disabled auto-checkpoint, 16 MiB journal limit, NORMAL main connection, SQLite >= 3.51.3 checked at open and pragma readback checked. An exclusive SQLite lock on a separate `.lock` file lasts for the writer's lifetime. Effects keyed by (consumer, epoch, position, subject), affected subjects, delivery digests, source frontier and checkpoint commit atomically. Checkpoint CAS fences stale workers; source/stream/order checks and stored digests reject changed re-delivery. Output tables contain identities/coordinates and digests, never fact values.
- Broker adapter and real reader-worker RPC, request kind `feed`. Synchronous `LogFeed.poll` runs inside the worker, not inside Promise.resolve on the server event loop. The adapter accepts commit/abort/epoch/seal input and strips to the contract.
- P2X adapter always requests `exact:true`, maps every tuple ordinal to a logical position, and requires a source-backed asynchronous lookup for the missing assertion/transaction IDs. One P2X operation retains its whole positions/txIds/commandIds group: copying operation-wide command IDs to every ordinal would falsely allocate the same commands new positions. Unknown tuple ordinals are refused. METADATA is never substituted for exact tuples.
- Journal adapter always labelled `A0-control`; no inferred decided stamp. Datomic native adapter explicitly throws `FeedUnavailable`, naming EXP-DF01.
- Public testkit `/feed` audit of an independently enumerated final source prefix, full identity content, commit positions, abort/epoch/seal accounting, per-entity subject order, unique command claims, byte-exact resume, required gap mutation rejection and a reusable 100-crashes-per-hook matrix with a mandatory duplicating split control.
- NS bench JSONL persistence replaced by this SQLite store. Its direct-subject affected set and receipt-clock lag remain explicitly **diagnostic A0**; DI01 and P3M remain responsible for the domain affected set and source-publication clocks. G0 builds, hashes and tests host, and host's alias factory is now actually called, so a clean checkout resolves its SQLite tests through public package aliases.
- Changeset for the public core and testkit subpaths. Host remains private. Only one internal testkit dev dependency was added to host; the final lockfile changes only that workspace link. All prior external resolutions were retained, and the final frozen offline install succeeded.
