# Stored-data reader audit

North star: P1 exact cuts and P3 journal completeness (`lab/SCOPE.md`, `lab/NORTH-STAR.md`, `lab/TARGETS.md`).

`data-audit.py` searched 800 tracked code files under packages, experiments and qualification. It begins with actual `:_tx/*` attributes, `_Transaction`, the `tx_meta`/attempt/claim and SQL receipt tables, binary KV receipt/position keys, RDF ledger IRIs and broker intent-log fields, then traces consumers and temporal lowering. The final inventory matches 80 stored-data files, 58 consumer files and 88 time-lowering files, with before/after hashes. Tests, generated historical copies, schema/name guards and write-only matches are retained as matches, not misclassified as production reads. The accepted replay implementation is outside this search and was not read.

No remaining current logical journal/feed/receipt reader found here applies the runtime/business clock to a position-bound journal. Generic entity/native/dependency queries are intentionally business-time queries; changing them based solely on the selected journal attribute would violate the explicit-validAt control. This is a source/call-path audit plus declared offline executions, not a completeness proof about absent code or a live engine qualification.
